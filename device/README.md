# `device/` -- real riva hardware artifacts (extracted)

These were pulled directly from the **stock riva fastboot ROM**
(`riva_images_V10.1.1.0.NCKCNFI_20181019.0000.00_7.1_cn`) present in this
workspace.

| File            | Source                                  | Notes                                  |
|----------------|-----------------------------------------|----------------------------------------|
| `riva.dtb`     | appended to `images/boot.img` zImage    | **Generic QRD DTB** (model "MSM8940-PMI8950 QRD SKU6"), *not* riva-specific -- re-extract the device `dtb` partition at bring-up for board-accurate panel/touch/regulator addresses. |
| `riva.dts`     | decompiled `riva.dtb` (dtc)             | 10,972 lines; source of the hardware facts in `docs/HARDWARE.md`. |
| `riva-adt.dtb` | generated by `tools/mkadt-riva.py`      | Apple Device Tree consumed by the shim/XNU. |
| `riva-adt.dts` | generated dts dump of the ADT           | human-readable form of the ADT. |
| `bootimg.cfg`  | `abootimg -x images/boot.img`           | load addresses used by `flash/build_bootimg.sh`. |

## How the DTB was extracted
The boot.img is a standard Android boot image. `abootimg -x` splits it into
`zImage` + `initrd.img`; the board DTB is **appended** to the zImage (no
separate "second" stage on this kernel). `tools/extract-dtb.py` scans for the
FDT magic `0xd00dfeed`, reads `totalsize` from the header, and writes a clean
`.dtb`.
